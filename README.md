# Crestly (2026 Edition)

A beautiful, high-performance messaging web application built using Bolt and VS Code

## 🔗 Live Application
* **Live Deployment Link:** [hello-crestly.vercel.app](https://vercel.app)

---

## 📅 Automated & Scheduled Messaging Engine
The platform features an advanced scheduling subsystem that allows users to cue and automate communications seamlessly:
* **⏱️ Precision Scheduling:** Compose messages and set specific future target execution dates (`dd-mm-yyyy`) and times (`--:--`).
* **🔁 Dynamic Recurrence Intervals:** Built-in automation options to fire messages **Once**, **Daily**, **Weekly**, or **Monthly** automatically.
* **👥 Context-Aware Delivery:** Intuitively syncs messaging cues directly to selected user channels or active group chat contexts (e.g., scheduling specialized tasks directly for contacts like `lee`).

---

## ✨ Dynamic Customization Suite
An integrated user interface customization system allows real-time visual configuration:
* **🌗 Dual-Theme Support:** Toggle instantly between high-contrast **Light Mode** and a polished, developer-friendly **Dark Mode**.
* **🎨 10-Color Accent Engine:** Seamless color shifting across ten curated options (Violet, Teal, Amber, Rose, etc.) that adapt dynamically across active controls and buttons.
* **⬡ Adaptive Bubble Layouts:** Switch your visual presentation instantly between smooth **Rounded** shapes or sharp geometric modern outlines.
* **💬 Independent Message Theming:** Fine-grained customization to independently toggle message chat threads between vibrant **Accent Highlights** or clean **Neutral Blocks**.

---

## 🛠️ Main Application Features
* 🤖 **Crestly AI Assistant :** A built-in intelligent companion ready to answer prompts, assist workflows, and maintain persistence across sessions.
* 🔐 **Secure Identity Flows:** Full Sign-In and Sign-Up structures handling validation errors reactively.
* 📂 **Organized Message Views:** Built-in category tags to filter conversations instantly between **All**, **Archive**, **Work**, and **Family**.
* ⚡ **Optimized State Transitions:** Fluid user interactions built using component micro-animations and utility styling.
